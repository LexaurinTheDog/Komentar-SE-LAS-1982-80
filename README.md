# Kommentar till lagen (1982:80) om anställningsskydd

Kommentar till svensk författning: **Lag (1982:80) om anställningsskydd** (SFS 1982:80), anställningsskyddslagen. Kommentaren omfattar **71 enheter** (70 paragrafer, varav tre upphävda eller ombetecknade, samt övergångsbestämmelserna) fördelade på 4 kommentarskapitel; vid varje paragraf återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2022:836** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2025-10-17).

## Innehåll

Se [INDEX.md](INDEX.md). Metoden beskrivs i [00-inledning.md](00-inledning.md).

## Metod

Kommentaren har utarbetats **uteslutande på grundval av lokalt material** (den officiella konsoliderade texten i SFS och författningsregistret), utan användning av kommersiella juridiska databaser. Lydelsen har maskinellt hämtats ordagrant ur den officiella texten. **Rättspraxis ingår inte i denna version** – den kommer att läggas till i ett senare skede.
